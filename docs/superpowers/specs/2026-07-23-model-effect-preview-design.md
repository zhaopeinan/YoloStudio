# 模型效果预览设计

日期：2026-07-23

## 1. 背景与目标

当前系统已经支持训练任务、训练后批量预测和预测结果审查，但缺少一个面向人工快速验证的效果预览模块。用户需要在不修改数据集标注的前提下：

1. 选择内置的未训练模型或某个训练任务生成的模型。
2. 选择数据集并逐张查看预测框、类别和置信度。
3. 上传视频后实时查看模型逐帧识别结果。
4. 保存、下载或删除带框结果视频。

本功能服务于模型效果快速确认和人工复核，不替代正式的标注、数据集版本、训练和评估流程。

## 2. 范围

### 2.1 本期包含

- 新增顶部工作流步骤“效果预览”，位置在“模型训练”和“评估与导出”之间。
- 图片预览和视频预览两个模式。
- 模型选择：
  - base:yolov8n.pt：项目内置的未训练模型。
  - run:{run_id}：已完成训练任务的 best.pt。
- 数据集选择和数据集图片逐张浏览。
- 预测框、类别名称、置信度和检测数量展示。
- 真实标注框与预测框独立显示/隐藏。
- 置信度阈值调整。
- 视频上传、后台逐帧推理、实时带框帧流、进度状态和结果视频保存。
- 结果视频播放、下载和删除。
- 预览结果独立存储，不修改原始数据集、原始视频、标注或模型。

### 2.2 本期不包含

- 浏览器端 ONNX/WebGPU 推理。
- 将视频识别结果自动写回数据集标注。
- 多目标跟踪、目标 ID 关联和态势图拼接。
- 多用户权限、远程对象存储和云端任务队列。
- 同时运行多个视频推理任务。

## 3. 用户体验

### 3.1 图片预览

页面顶部提供预览设置：

- 模型下拉框。
- 数据集下拉框。
- 置信度阈值滑块和数值输入，支持小目标任务使用低阈值。
- “显示预测框”和“显示真实标注”开关。

主区域由图像画布和结果信息组成：

- 上一张、下一张和当前序号。
- 画布支持缩放。
- 预测框使用类别颜色，框旁显示类别和置信度。
- 真实标注使用独立的线型或颜色，避免和预测框混淆。
- 右侧显示当前图像的检测数量和类别汇总。
- 缺少预测结果时显示明确的空状态，不与加载失败混淆。

底部提供快速浏览状态：

- 已查看/总图像数。
- 有预测、无预测和处理失败的状态标识。
- 选择新模型或新数据集后清空上一组临时预测结果。

图片预览预测只读，不会保存到 annotations 表。用户确认需要保留的框，仍通过标注工作台编辑和保存。

### 3.2 视频预览

视频页面提供：

- 文件选择和拖拽上传。
- 模型选择。
- 置信度阈值。
- 抽帧间隔，默认每帧处理，也可选择每 2 帧或每 3 帧处理。
- 任务状态：准备中、推理中、已完成、失败。
- 当前处理帧、总帧数和进度。
- 实时带框帧显示。
- 完成后播放结果视频、下载结果视频和删除本次结果。

实时帧流用于低延迟预览，可能不包含音频。任务完成后使用 ffmpeg 将原视频音频合并到结果视频；原视频没有音频时直接生成无声结果视频。

删除本次结果只删除当前预览任务目录和记录，不删除原视频。

## 4. 技术架构

### 4.1 模型引用

预览请求不直接暴露任意文件路径，而使用受控的模型引用：

- base:yolov8n.pt 映射到项目内置权重。
- run:{run_id} 映射到对应训练任务的 ultralytics/weights/best.pt。

服务端验证训练任务必须存在且模型文件可读。失败时返回可理解的错误，而不是将 Python 异常直接展示给用户。

### 4.2 图片接口

    POST /api/preview/images/{image_id}

请求：

    {
      "model_ref": "run:1",
      "confidence_threshold": 0.05
    }

响应包含：

- 图像 ID、原始尺寸和图像 URL。
- 预测框：类别 ID、类别名称、颜色、归一化坐标和置信度。
- 当前图像已有真实标注框。
- 模型引用和实际使用的阈值。

图片预测可以在内存中完成，不创建持久化预测任务，避免用户逐张浏览时污染实验记录。

### 4.3 视频接口

    POST   /api/preview/video-jobs
    GET    /api/preview/video-jobs/{id}
    GET    /api/preview/video-jobs/{id}/stream
    GET    /api/preview/video-jobs/{id}/result
    DELETE /api/preview/video-jobs/{id}

视频上传接口使用 multipart/form-data，参数包含模型引用、置信度阈值和抽帧间隔。接口快速返回预览任务 ID，实际推理由本地后台任务执行。

stream 使用本机 HTTP multipart/x-mixed-replace 返回带框 JPEG 帧。前端边接收边显示；状态接口用于进度、错误和完成状态，避免把控制信息混入帧流。

### 4.4 持久化

新增 PreviewJob 记录，至少包含：

- ID、项目 ID、模型引用。
- 可选训练任务 ID。
- 来源类型和原视频文件名。
- 置信度阈值、抽帧间隔。
- 状态、进度、当前帧、总帧数。
- 原视频路径、结果视频路径、错误信息。
- 创建时间、更新时间和完成时间。

结果目录：

    workspace/projects/{project_id}/previews/{preview_id}/
    ├── source.<原扩展名>
    ├── result.mp4
    ├── preview.json
    └── frames/

任务完成后可以清理中间帧；任务失败时清理不完整结果或将其标记为可清理状态。删除接口必须同时删除数据库记录和文件目录。

## 5. 推理与资源策略

- 图片和视频共用模型解析与预测框转换逻辑，保证类别 ID 和坐标格式一致。
- 视频推理使用当前设备检测结果，默认优先 MPS，其次 CPU。
- 同一时间只允许一个视频预览任务运行。
- 上传限制包括扩展名、文件大小和可解码性检查。
- 处理过程中定期更新任务记录，前端可以在刷新后恢复任务状态。
- 磁盘不足、模型不存在、视频无法解码和推理异常都要将任务置为 failed 并记录中文错误信息。
- 原视频文件只读保存；结果视频使用独立文件名。

## 6. 验收标准

1. 用户可以在“效果预览”中选择 yolov8n.pt 或已完成训练任务的 best.pt。
2. 用户可以选择一个已保存数据集并逐张查看预测框。
3. 真实标注框和预测框可以独立显示或隐藏。
4. 调整置信度阈值后，当前图片的预测结果可以重新加载。
5. 上传视频后 1 秒内出现任务状态，推理过程中持续显示带框帧。
6. 视频完成后可以播放和下载 result.mp4。
7. 删除预览结果后，结果文件和预览记录均消失，原视频和模型仍存在。
8. 训练、标注、正式评估和模型导出流程不受影响。
9. 后端接口测试覆盖模型解析、图片预测、视频任务生命周期、文件校验和删除。
10. 前端测试覆盖工作流导航、模型/数据集选择、图片切换、阈值更新、视频状态、下载和删除。
11. 使用当前项目的一段短视频完成一次 MPS 手工验证。
