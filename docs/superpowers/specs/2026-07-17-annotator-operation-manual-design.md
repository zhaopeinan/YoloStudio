# YOLO Trainer 零基础标注员操作手册设计

日期：2026-07-17

## 目标

制作一份排版美观、使用 MiSans 字体的 Word 操作手册，使没有目标检测、YOLO 或数据标注经验的标注员，能够仅按文档完成以下闭环：

1. 从本机图片创建并导入演示数据集。
2. 创建项目类别并理解类别使用规则。
3. 逐图绘制、修正、保存边界框。
4. 检查标注质量并创建冻结数据集版本。
5. 使用标注版本启动训练并观察训练状态。
6. 对训练后模型执行预测分析并查看识别效果。
7. 根据误报、漏报和类别混淆回到标注页修正数据，再创建新版本并重新训练。

## 受众与写作原则

- 受众为零背景知识的单机标注员，不假设其理解 YOLO 坐标、训练集切分或置信度阈值。
- 每个步骤使用明确的动作句，不用后端 API、数据库实体或代码术语解释界面操作。
- 每一步均配当前中文版真实界面截图；关键点击位置使用编号框、箭头或局部高亮。
- 每一步固定包含“要做什么”“怎么操作”“完成标志”，必要时增加“注意”或“出错时怎么办”。
- 先讲最短可用路径，再在对应步骤解释缩放、小目标、边缘案例和预测回流等进阶操作。

## 演示数据策略

- 从当前已有数据集中复制少量图片，创建独立演示数据，不移动、不删除、不修改原数据集。
- 演示项目和数据集采用统一、易识别的中文名称，避免截图中混入历史测试记录。
- 演示数据规模以能展示类别、标注、版本切分、训练和预测为准，同时控制真实训练耗时。
- 截图过程中不执行会影响现有数据的删除、回收站清理或覆盖操作。
- 如训练耗时较长，可使用已完成演示训练任务继续展示预测分析，但手册仍完整说明启动和等待训练的过程。

## 文档结构

### 前置部分

- 封面：文档名称、适用版本、适用角色和日期。
- 一页快速认识：六步顶部导航与完整闭环图。
- 开始前检查：前后端服务、图片目录、类别清单和训练所需时间。
- 标注合格标准：框要贴合、类别要正确、遮挡目标仍要标、极小目标如何处理。

### 第一部分：创建演示数据集

- 打开“项目与数据”。
- 填写图片来源路径并扫描。
- 核对图片数量和分组预览。
- 填写项目名、数据集名并导入。
- 识别导入成功状态和常见路径错误。

### 第二部分：配置类别

- 进入“类别管理”。
- 新建类别并理解项目级类别库。
- 选择当前绘制类别。
- 说明类别名称确认后再开始批量标注，避免同义类别重复。

### 第三部分：完成图像标注

- 认识图像列表、画布、工具栏和属性栏。
- 选择未标注图像。
- 在目标外沿拖动创建边界框。
- 放大、缩小和平移图像后标注小目标。
- 选中、移动、缩放、改类别和删除错误框。
- 添加遮挡、伪装、小目标等边缘案例标签。
- 使用“保存”和“保存并下一张”。
- 判断当前图像是否已保存，并处理切图前的未保存提醒。

### 第四部分：检查质量并创建训练版本

- 进入“质量与版本”。
- 查看未标注、极小框、重复框、无效框等问题。
- 从问题样本返回标注页修正。
- 确认训练准备状态。
- 设置版本名称、类别子集并创建数据集版本。
- 解释冻结版本不会随之后的标注修改自动变化。

### 第五部分：训练模型

- 进入“模型训练”。
- 选择最新数据集版本和 Nano 模型。
- 使用适合首次验证的低成本参数启动训练。
- 查看排队、准备、训练中、完成和失败状态。
- 读取关键指标和产物位置，不要求标注员解释所有训练日志。

### 第六部分：查看识别效果

- 进入“评估与导出”。
- 选择训练任务、图片范围和置信度阈值。
- 启动预测分析。
- 对照真实标注与模型预测图层。
- 理解匹配、误报、漏报和类别混淆。
- 从失败样本打开原图。

### 第七部分：效果不好时迭代

- 判断问题来自漏标、框不准、类别错误、样本不足还是困难样本不足。
- 回到标注页修正失败样本，并补充同类边缘案例。
- 重新执行质量检查，创建新版本。
- 使用相同或调整后的训练配置重新训练。
- 对比两次训练和预测结果，保留更优版本。
- 给出“不要直接修改旧冻结版本”“不要只修验证图而忽略同类样本”等注意事项。

### 附录

- 一页标注质量检查清单。
- 常见故障排查：无法导入、无法画框、框未显示、无法创建版本、训练失败、预测无结果。
- 常用术语：真实标注（GT）、模型预测（Pred）、置信度、误报、漏报、训练/验证/测试集。

## 视觉与版式

- 文档类型：面向操作岗位的图文 SOP，A4 纵向。
- 字体：中文、英文和数字统一使用 MiSans；在 Word 样式和所有直接格式中显式指定。
- 版式基于紧凑参考指南风格，使用清晰的章节色带、步骤编号、完成标志和克制的蓝绿色强调色。
- 截图按页面可读宽度放置，避免把整页界面缩得过小；必要时使用全景图加局部放大图。
- 截图下方使用统一图题，例如“图 3-4：拖动边界框四角修正范围”。
- 警告、提示和完成标志采用三种固定样式，不使用高饱和装饰背景。
- 页眉显示“YOLO Trainer 标注员操作手册”，页脚显示章节和页码。

## 截图清单与制作规则

- 六步导航总览。
- 数据集扫描、预览、导入成功。
- 类别创建和类别列表。
- 标注工作台总览、创建框、缩放后小目标标注、属性修改、边缘标签、保存状态。
- 质量问题列表、准备状态、版本创建和版本结果。
- 训练配置、训练中、训练完成和指标区域。
- 预测配置、预测结果、失败类型、GT/Pred 叠加与打开失败样本。
- 回流修正、创建新版本、重新训练和实验对比。

所有截图应：

- 来自同一套演示项目，名称和编号连续。
- 隐去与手册无关的本机绝对路径细节，必须展示路径时仅保留操作所需部分。
- 不包含浏览器调试工具、系统通知、其他标签页或无关测试记录。
- 对关键操作增加标注，但不遮挡按钮文字、状态或目标图像。

## 验证与验收

- 内容验证：逐项对照当前前端操作和后端行为，不描述不存在的按钮或自动行为。
- 闭环验证：实际走通“演示数据 → 标注 → 版本 → 训练 → 预测 → 回流修正”主路径。
- 字体验证：DOCX 样式和运行文本均指定 MiSans，渲染环境加载 MiSans 后不出现字体替换。
- 布局验证：将 DOCX 渲染为逐页 PNG，逐页检查截图清晰度、图题配对、分页、重叠、裁切和空白。
- 文档验收：零基础读者可按步骤独立完成一次标注和一次训练效果检查，并知道效果不好时从哪里返回继续修正。

## 非目标

- 不介绍 Python、Ultralytics 安装、数据库结构或 API 调用。
- 不作为模型算法原理教材，不详细解释损失函数和网络结构。
- 不执行或演示现有数据集、版本、训练记录的删除操作。
- 不修改 YOLO Trainer 的产品代码和交互逻辑。
