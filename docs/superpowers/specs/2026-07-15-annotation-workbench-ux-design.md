# YOLO Trainer 标注工作台体验优化设计

日期：2026-07-15

## 目标

将“图像标注”页面重组为画布优先、适合单人连续标注的专业工作台，让用户能够清楚完成“选图、画框、保存、下一张”主流程，同时保留边界框精细修正、边缘案例标记、预测审查和高级筛选能力。

本次改造同时把桌面端六步工作流导航从左侧移动到顶部，释放横向空间。后端 API、数据库结构、YOLO 标注格式、画框算法和预测审查数据结构保持不变。

## 已确认原则

- 优先服务连续快速标注，不让筛选器和坐标表单占据首屏中心。
- 桌面端采用“图像列表、标注画布、当前框属性”三栏结构，画布获得最大宽度。
- 核心动作固定在画布上方；低频功能进入折叠区、抽屉或更多操作菜单。
- 移动端不把三栏简单纵向堆叠，改用“画布、图像、属性”三个视图标签。
- 保留现有未保存草稿保护机制，任何自动切图都必须以保存成功为前提。

## 全局导航调整

### 桌面端

六个工作流步骤改为位于运行状态区下方的横向进度导航：

1. 项目与数据
2. 类别管理
3. 图像标注
4. 质量与版本
5. 模型训练
6. 评估与导出

每个步骤显示编号、名称和简短状态。已完成步骤显示完成图标，当前步骤使用强调色背景和底部强调线，锁定步骤降低对比度并保留锁定原因提示。导航不显示原左侧栏中的长描述。

导航容器在宽度不足时横向滚动，步骤文字不压缩、不换成多行。主体内容改为全宽，不再为左侧导航预留固定列。

### 移动端

在 `820px` 以下继续使用现有“当前步骤”选择器，不显示横向步骤导航。选择器仍负责展示全部步骤及其可用状态。

## 桌面标注布局

标注页由顶部工具栏和固定高度三栏工作台组成：

```text
┌ 当前类别 | 上一张 | 图像进度 | 下一张 | 图层 | 保存状态 | 保存 | 保存并下一张 ┐
├────────────┬────────────────────────────┬──────────────┤
│ 图像浏览栏  │                            │ 当前边界框    │
│ 搜索与状态  │         标注画布            │ 类别与标签    │
│ 图像列表    │                            │ 轨迹 ID       │
│ 分页        │                            │ 高级坐标      │
├────────────┴────────────────────────────┴──────────────┤
│ 当前图像摘要与必要提示                                  │
└────────────────────────────────────────────────────────┘
```

三栏分别独立滚动，页面本身不因长图像列表或多个边界框编辑器无限增长。桌面列宽约束为：左栏 `240-280px`，右栏 `280-320px`，中间画布占据剩余空间。

### 顶部标注工具栏

工具栏承担高频操作：

- 当前绘制类别选择。
- 上一张、下一张图像。
- 当前图像序号和标注进度。
- 真实标注与模型预测图层开关，仅在预测审查状态下显示。
- 保存状态：`已保存`、`有未保存修改`、`保存中`或失败原因。
- 独立“保存”按钮。
- 主按钮“保存并下一张”。
- 更多操作菜单，承载“复制上一张标注”和“复制下一张标注”等低频命令。

删除现有四枚“标注就绪状态”胶囊。缺少数据集、类别或选中图像时，工具栏下方只显示一条可执行的中文提示。

### 图像浏览栏

左栏默认只显示：

- 文件名搜索。
- 标注状态筛选。
- 打开高级筛选的按钮。
- 当前结果数量与分页。
- 可滚动图像列表。

图像项显示短文件名、标注数量和状态，平台或高度作为次要信息。完整相对路径放入 `title` 提示，不在列表中占据多行。当前图像和未标注图像使用明确但克制的状态区分。

平台、类别、识别结果、边缘案例标签和高度范围移入高级筛选抽屉。抽屉提供“应用筛选”和“清除筛选”，关闭后保留已应用条件，并在入口显示已启用条件数量。

### 画布区

画布是页面视觉中心，使用稳定的可用高度和深色背景完整展示图像，不裁切原图。保留现有拖动画框、选框、移动和四角缩放能力。

画布下方显示短文件名、图像尺寸、平台、高度和当前框数量。没有图像时，根据缺失条件显示单一空状态，不同时展示多个准备状态。

### 边界框检查器

右栏一次只重点编辑当前选中的边界框：

- 类别。
- 边缘案例标签和常用标签预设。
- 目标轨迹 ID。
- 删除边界框。
- 方向微调按钮。
- 默认折叠的归一化 `X`、`Y`、`W`、`H` 坐标。

右栏顶部显示当前图像的边界框列表。点击列表项切换当前框；画布选框同步更新右栏。没有选中框时，显示框列表和“在图像上拖动以添加边界框”的简短提示，不重复渲染全部框的完整表单。

预测审查摘要位于右栏的独立区块，提供误报、漏报和类别混淆统计及现有修正操作，但不挤压基础属性编辑器。

## 核心交互

### 初始选择

进入标注页时：

- 如果已有有效选中图像，保持当前选择。
- 否则优先选择当前筛选结果中的第一张未标注图像。
- 如果没有未标注图像，选择当前结果第一张图像。

### 新建与编辑边界框

顶部类别选择决定新建边界框的类别。选中已有边界框后，右栏类别选择只修改该框，不改变顶部新建类别。

画布、边界框列表和检查器共享同一个 `selectedAnnotationId`。删除当前框后，选择相邻框；没有剩余框时回到未选中状态。

### 保存并下一张

“保存并下一张”执行以下顺序：

1. 提交当前图像标注。
2. 保存成功后，将当前草稿状态标记为已保存。
3. 优先选择当前筛选结果中的下一张未标注图像。
4. 如果没有后续未标注图像，选择普通下一张图像。
5. 如果已经到达当前结果末尾，停留在当前图像并提示“当前列表已完成”。

保存失败时不得切图，当前标注草稿和选中边界框保持不变，并在工具栏显示错误。

手动上一张、下一张或点击图像列表时，继续使用现有未保存修改确认机制。

## 移动端布局

移动端标注页顶部保留紧凑类别选择、保存状态和“保存并下一张”。主体使用三个分段标签：

- `画布`：默认视图，包含图像、画框能力和前后切图。
- `图像`：包含搜索、状态筛选、分页和图像列表。
- `属性`：包含边界框列表、当前框属性和预测审查。

切换标签不清空草稿、筛选或选中框。按钮、标签和长文件名不得造成横向溢出。

## 前端结构

现有 `App` 继续持有业务状态和 API 调用。本次在不改变数据所有权的前提下，将标注页面展示拆分为职责明确的组件或局部组件：

- `AnnotationToolbar`：类别、图像导航、保存状态和高频命令。
- `AnnotationImageBrowser`：基础筛选、分页和图像列表。
- `AnnotationFilterDrawer`：低频高级筛选。
- `AnnotationCanvas`：图像、SVG 叠加层和画布摘要。
- `AnnotationInspector`：框列表、当前框属性和预测审查。
- `AnnotationMobileTabs`：移动端三个视图的切换。

`WorkflowShell` 改为顶部横向导航结构。步骤状态计算、URL hash、锁定步骤行为和未保存标注离开确认保持现有逻辑。

## 错误与空状态

- 无数据集：提示返回“项目与数据”加载或导入数据集。
- 无类别：提示进入“类别管理”创建类别。
- 筛选无结果：显示清除筛选操作，不显示空白画布。
- 图像加载失败：显示文件名和重试操作，标注草稿不被清空。
- 保存失败：保留草稿，不自动切图。
- 高级筛选请求失败：抽屉内显示错误，当前已加载图像列表保持可用。
- 当前列表完成：停留在末张并显示完成提示，不循环回第一张。

## 测试与验证

前端自动测试覆盖：

- 桌面端不再渲染左侧工作流导航，顶部渲染六个步骤。
- 当前、已完成和锁定步骤状态及点击行为保持正确。
- 基础筛选与高级筛选抽屉正确分离，应用和清除条件有效。
- 进入标注页时优先选择第一张未标注图像。
- 画布、框列表和检查器的选中状态同步。
- 坐标编辑区默认折叠，展开后仍可修改归一化坐标。
- 保存成功后“保存并下一张”选择下一张未标注图像。
- 保存失败时不切图且草稿保持。
- 手动切图和离开步骤仍触发未保存确认。
- 移动端三个标签切换不丢失状态。
- 预测图层、失败统计和预测修正操作继续工作。

浏览器验证：

- 桌面视口下顶部导航不遮挡、不换成多行，标注画布宽度明显大于现状。
- 三栏拥有稳定高度和独立滚动，工具栏在连续标注时始终可见。
- `390px` 视口下使用移动步骤选择器和标注视图标签，无横向溢出或文字重叠。
- 长文件名、多个边界框、筛选无结果、保存中和保存失败状态均保持清晰。

完成后运行前端测试和生产构建，并在本地运行页面进行桌面与移动端实测。后端逻辑未修改时，运行后端现有测试作为回归确认。

## 验收标准

- 桌面端左侧工作流导航完全移除，六步导航位于顶部且所有页面一致。
- 标注页首屏以画布为中心，高级筛选不再长期占据首屏。
- 用户可明确完成“画框、保存并下一张”的连续操作。
- 图像切换、保存状态和当前类别在首屏始终可见。
- 右栏只突出当前边界框，精细坐标默认折叠。
- 保存失败不会丢失草稿或错误切图。
- 预测审查、边缘案例标签、轨迹 ID 和复制相邻标注能力均保留。
- 桌面和移动端无横向溢出、控件重叠或不可达操作。
- 前端测试、生产构建和后端回归测试通过。

## 非目标

- 不修改后端 API、数据库、训练或预测执行逻辑。
- 不改变 YOLO 标签格式和类别映射规则。
- 不重写 SVG 画框、移动和缩放算法。
- 不增加多人协作、快捷键自定义、自动保存或新的全局状态库。
- 不在本次改造中重构标注页之外的业务组件。
