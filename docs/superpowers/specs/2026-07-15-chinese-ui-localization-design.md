# YOLO Trainer 中文界面设计

日期：2026-07-15

## 目标

将 YOLO Trainer 当前所有用户界面统一为准确、自然的简体中文，并修复顶部状态卡片中工作空间与数据库长路径溢出容器的问题。

本次改造只调整展示层，不修改 API、数据库字段、训练配置结构、产物目录或训练行为。

## 已确认决策

- 采用单语言中文界面，不引入国际化框架。
- 静态文案、动态状态、操作反馈、校验错误、空状态、表头、筛选项、占位符、工具提示和无障碍标签全部中文化。
- 行业缩写保留，并在需要消除歧义的位置使用“中文名称（缩写）”，例如“真实标注（GT）”和“模型预测（Pred）”。
- `YOLO`、`mAP50`、`F1`、`ONNX`、`TensorRT`、`CPU`、`CUDA`、`MPS` 等标准名称不翻译。
- 模型名、类别名、平台名、文件名、文件路径、设备值、原始训练日志和底层异常原文保持不变。
- 对用户展示的错误说明使用中文；当异常只提供底层英文原文时，在中文上下文中保留该原文，避免丢失排错信息。

### 状态与结果

训练、预测和导出的机器状态值通过集中格式化函数显示，不修改接口原始值。核心映射如下：

| 原始值 | 中文显示 |
| --- | --- |
| queued | 排队中 |
| preparing | 准备中 |
| running | 运行中 |
| completed | 已完成 |
| failed | 失败 |
| cancelled | 已取消 |
| pending | 等待中 |
| matched | 匹配正确 |
| false_positive | 误报 |
| false_negative | 漏报 |
| class_confusion | 类别混淆 |

训练上下文可使用“训练中”，预测上下文可使用“预测中”；状态映射函数应允许调用方提供上下文，而不改变后端枚举。

### 专业术语

- `Confidence threshold`：置信度阈值。
- `Precision`：精确率。
- `Recall`：召回率。
- `Confusion Matrix`：混淆矩阵。
- `Threshold Scan`：阈值扫描。
- `Ground Truth / GT`：真实标注（GT）。
- `Prediction / Pred`：模型预测（Pred）。
- `Box loss`：边界框损失。
- `Class`：类别。
- `Edge tags`：边缘案例标签。
- `Track ID`：目标轨迹 ID。
- `Artifact`：产物。
- `Run`：训练任务；在实验编号等紧凑位置可显示为“任务”。

类别和标签的实际数据值不翻译。例如用户创建的 `drone` 类别仍显示为 `drone`，已有 `occluded` 标签值也保持原值；仅预设按钮的展示名称翻译为“遮挡”等中文含义。

## 实现设计

### 集中文案与格式化

保持现有单文件组件结构，不引入新的运行时依赖。静态 JSX 文案直接替换为中文；重复使用的状态、失败类型、质量问题类型和边缘案例标签通过现有格式化函数或新增的小型映射常量集中管理。

该边界可避免同一状态在列表、看板和筛选器中出现不同译法，同时不为了单语言界面引入完整国际化框架。

### 路径卡片

顶部状态卡片保持三列布局。每个卡片的文本内容容器必须具备 `min-width: 0`，路径值继续使用单行省略号：

- 路径不允许撑宽网格列或越过卡片边界。
- 窄视口下仍由现有响应式规则自然换列。
- 完整路径写入路径元素的 `title` 属性，鼠标悬停时可查看。
- 路径本身保持原文，不做中间截断或内容改写。

### 错误与日志

- 前端自己产生的错误提示和校验信息全部翻译为中文。
- API 返回的可识别错误可通过中文前缀或映射说明其业务含义。
- 原始训练日志、Ultralytics 输出和文件系统异常原文保持不变。
- 不对日志内容做字符串替换，避免破坏搜索、复制和问题定位。

## 测试设计

- 更新前端现有测试中依赖英文文案的查询和断言。
- 增加核心模块中文标题、按钮、筛选项和状态映射的断言。
- 增加工作空间和数据库路径元素的完整 `title` 属性断言。
- 增加状态卡内容容器可收缩及路径省略样式的检查。
- 保持现有数据集导入、标注、训练、预测和导出交互测试全部通过，证明仅展示层发生变化。
- 运行前端完整测试和生产构建。
- 在桌面与窄屏视口中进行浏览器检查，确认路径不溢出、中文按钮不被截断、控件之间不重叠。

## 验收标准

- 页面正常工作流程中不再出现应翻译的英文界面文案。
- 行业缩写、模型名、路径、数据值和原始日志按设计保持原样。
- 同一状态或失败类型在不同模块中使用一致译法。
- 工作空间和数据库长路径不会超出卡片边界，并可通过悬停查看完整值。
- 中文文案在桌面和窄屏下不溢出按钮、标签、表格或面板。
- 前端测试和生产构建通过，现有核心交互行为无回归。

## 非目标

- 不提供中英文语言切换。
- 不翻译后端 API 字段、数据库内容和产物清单。
- 不翻译用户自定义类别、标签或数据集名称。
- 不修改训练日志和第三方库输出。
- 不调整页面信息架构或视觉主题。
