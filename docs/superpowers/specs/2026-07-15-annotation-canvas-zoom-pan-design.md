# YOLO Trainer 标注画布缩放与平移设计

日期：2026-07-15

## 目标

为图像标注画布增加适合小目标的缩放和平移能力，使用户能够放大原始图像后继续准确新建、移动和调整边界框，同时保持 YOLO 归一化坐标、后端 API 和保存数据完全不变。

本次优先优化桌面端单人标注流程。移动端提供按钮缩放和可滚动画布，不在本轮加入双指缩放手势。

## 已确认交互

- 鼠标滚轮以光标所在位置为中心缩放。
- 按住空格后使用鼠标左键拖动画布。
- 输入框、下拉框和可编辑控件获得焦点时，空格保持原有输入行为，不进入平移模式。
- 画布工具栏提供缩小、当前倍率、放大、`100%` 和“适应窗口”。
- 手动缩放范围为 `25%–800%`；“适应窗口”可根据高分辨率图像尺寸临时低于 `25%`。
- 点击缩小或放大按钮时按离散倍率级别变化。
- 双击倍率显示恢复“适应窗口”。
- 切换图像后恢复“适应窗口”。
- 平移过程中不创建边界框；松开空格后恢复正常画框。
- 缩放和平移不产生未保存标注状态。

## 布局

缩放工具栏位于中央画布标题栏右侧，不占用全局标注工具栏空间：

```text
┌ 标注与审查 / 标注                 [−] [250%] [+] [1:1] [适应] ┐
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                   可缩放、可平移图像与标注层                  │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

缩小、放大和适应窗口使用图标按钮并提供中文工具提示；倍率使用紧凑按钮显示；`100%` 使用 `1:1` 文案。控件尺寸固定，倍率文字变化不得引起标题栏布局跳动。

## 视口模型

画布使用以下前端状态：

```ts
type CanvasViewport = {
  zoom: number;
  panX: number;
  panY: number;
  mode: "fit" | "manual";
};
```

- `zoom` 使用显示比例，`1` 表示原始像素的 `100%`。
- `panX`、`panY` 使用画布视口 CSS 像素。
- `mode="fit"` 时，根据原始图像尺寸和画布可用尺寸自动计算显示倍率。
- 用户使用滚轮、缩放按钮或 `1:1` 后进入 `manual` 模式。
- 点击“适应窗口”或双击倍率后进入 `fit` 模式。
- `isPanning`、空格键按下状态和拖动起点作为瞬时交互状态单独管理，不进入持久视口对象。

使用以下固定倍率级别：

```ts
const zoomLevels = [0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4, 6, 8];
```

按钮选择当前倍率相邻的上一档或下一档。滚轮缩放使用连续变化并限制在 `0.25–8` 范围内。

## 渲染结构

图像和 SVG 标注层必须位于同一个变换容器中：

```text
annotation-canvas-viewport
└── annotation-transform-layer  translate(panX, panY) scale(zoom)
    ├── image
    └── svg.annotation-overlay
```

变换原点固定为左上角。图像元素使用其自然像素尺寸作为变换前基础尺寸，SVG 使用相同宽高并保持 `viewBox="0 0 1 1"`，因此现有标注仍使用 `0–1` 归一化坐标。

边界框可见描边和缩放控制点继续使用 `vector-effect="non-scaling-stroke"`，保证不同倍率下框线与控制点描边保持稳定。控制点的几何尺寸需根据当前倍率反向补偿，避免放大后控制点遮挡小目标。

## 坐标换算

### 画框、选框与调整

所有指针操作必须转换到未缩放图像坐标：

```ts
imageX = (pointerX - viewportLeft - panX) / zoom;
imageY = (pointerY - viewportTop - panY) / zoom;
normalizedX = imageX / naturalWidth;
normalizedY = imageY / naturalHeight;
```

结果继续限制在 `0–1` 范围内。边界框宽高、中心点和保存 payload 不加入倍率或平移偏移。

当前实现若直接使用变换后 SVG 的 `getBoundingClientRect()` 计算归一化坐标，也必须通过测试确认缩放和平移后结果与未缩放时一致；不得同时重复扣除变换值。

### 光标中心缩放

滚轮缩放前记录光标对应的图像坐标，缩放后重新计算平移量，使同一图像坐标仍位于光标下方：

```ts
imagePointX = (cursorX - panX) / oldZoom;
nextPanX = cursorX - imagePointX * nextZoom;
```

Y 轴使用相同计算。缩放按钮以画布视口中心作为缩放锚点。

## 平移规则

- 仅在画布区域内且空格处于按下状态时，左键按下开始平移。
- 平移模式下画布光标显示为抓手，拖动时显示抓取状态。
- 平移事件不得冒泡到画框、选框移动或缩放手柄逻辑。
- `keyup`、窗口失焦、指针取消和组件卸载时必须结束平移，防止画布卡在抓取状态。
- 平移量受到边界约束：图像较小的一轴保持居中；图像大于视口时至少保留一部分图像可见，不允许整张图被拖出视口。
- 在 `fit` 模式下首次拖动时切换到 `manual`，保留当前计算出的适应倍率。

## 适应窗口

适应倍率通过以下规则计算：

```ts
fitZoom = Math.min(
  viewportWidth / naturalWidth,
  viewportHeight / naturalHeight,
  1,
);
```

适应窗口默认不把小于视口的图像放大到超过 `100%`。为确保高分辨率图像能够完整显示，适应倍率不受手动缩放 `25%` 下限约束。图像在视口中水平和垂直居中。

以下情况重新计算适应窗口：

- 新图像加载完成。
- 用户切换图像。
- 画布区域尺寸变化且当前处于 `fit` 模式。
- 用户点击“适应窗口”或双击倍率。

手动倍率模式下调整窗口尺寸只重新约束平移，不覆盖用户倍率。

## 桌面键盘与滚轮处理

- 监听画布区域上的 `wheel`，调用 `preventDefault()` 阻止页面滚动，仅在指针位于画布时缩放。
- 空格键监听忽略 `input`、`textarea`、`select`、`button` 和 `contenteditable` 目标。
- 空格按下时阻止页面滚动，设置平移准备状态。
- 空格抬起后立即退出平移准备状态。
- 不新增全局快捷键配置，也不改变现有表单键盘行为。

## 移动端

- 移动端“画布”标签显示同一套缩放工具栏。
- 使用缩小、放大、`1:1` 和适应窗口按钮控制倍率。
- 放大后通过画布容器滚动查看图像。
- 不启用空格拖动。
- 不实现双指缩放、惯性平移或手势冲突处理。
- 工具栏按钮在 `390px` 视口内不得溢出；必要时允许工具栏横向滚动，但不压缩图标。

## 组件边界

新增职责明确的前端单元：

- `annotation-viewport.ts`：倍率限制、相邻倍率、适应窗口、光标中心缩放和平移约束纯函数。
- `annotation-viewport.test.ts`：纯函数单元测试。
- `AnnotationCanvasToolbar.tsx`：缩放按钮、倍率显示和工具提示。
- `App.tsx`：持有当前图像的视口状态，接入图像尺寸、ResizeObserver、滚轮、空格和平移事件，并继续拥有现有标注业务状态。

不引入第三方缩放库。当前需求只涉及一个图像和一个 SVG 叠加层，使用局部状态和纯函数更容易保证归一化坐标正确。

## 错误与边界状态

- 图像自然尺寸尚未获得时禁用 `1:1` 和适应窗口，保持加载状态。
- 图像加载失败时沿用现有错误状态，不执行缩放计算。
- 画布尺寸为零时不更新视口，等待下一次有效尺寸变化。
- 非有限倍率、平移或尺寸输入回退到适应窗口初始值。
- 达到 `25%` 或 `800%` 时禁用对应缩放按钮。
- 切图时先结束平移和指针交互，再重置视口，避免旧图拖动状态污染新图。
- 缩放和平移不得改变 `annotationsDirty`。

## 测试

纯函数测试覆盖：

- 手动倍率限制在 `0.25–8`，适应窗口倍率可低于 `0.25`。
- 相邻倍率按钮选择正确档位。
- 适应窗口倍率和居中平移正确。
- 光标中心缩放前后指向同一图像坐标。
- 图像较小和较大情况下的平移约束。
- 非有限输入回退行为。

组件与应用测试覆盖：

- 缩放工具栏显示当前倍率和正确禁用状态。
- 点击放大、缩小、`1:1` 和适应窗口更新视口。
- 切换图像恢复适应窗口。
- 输入框内按空格不进入平移。
- 画布内空格加左键拖动更新平移。
- 平移期间不创建新边界框。
- 缩放后新建边界框仍产生正确归一化坐标。
- 缩放后移动和调整边界框仍产生正确归一化坐标。
- 缩放和平移不触发未保存状态。
- 移动端只使用按钮缩放，并保持页面无横向溢出。

浏览器验收覆盖：

- 当前桌面窗口下测试适应窗口、`100%`、`400%` 和 `800%`。
- 在 `400%` 和 `800%` 下标注小目标，框线清晰且控制点不遮挡目标。
- 滚轮缩放保持光标目标位置稳定。
- 空格拖动流畅，松开后立即恢复画框。
- 左右栏和顶部工具栏不被放大内容挤压。
- `390px` 视口下按钮可达，放大画布可滚动，无页面级横向溢出。

## 验收标准

- 用户可将图像放大到 `800%` 并准确标注小目标。
- 缩放和平移后边界框仍与图像目标对齐。
- 保存结果与未缩放标注使用相同 YOLO 归一化坐标格式。
- 滚轮以光标为中心缩放，空格加左键可平移。
- 缩放和平移不会制造未保存标注状态。
- 切图后自动恢复适应窗口。
- 框线和控制点在所有倍率下清晰、尺寸稳定。
- 桌面和移动端均无页面级横向溢出。
- 前端测试和生产构建通过，后端无需修改。

## 非目标

- 不实现移动端双指缩放。
- 不增加小地图、旋转、图像增强或全屏模式。
- 不改变后端 API、数据库或 YOLO 标签格式。
- 不引入第三方画布或图像查看器库。
- 不修改预测、训练和质量审查逻辑。
